Justificación Técnica de este Diseño:
Pydantic Settings: No usamos diccionarios simples. Usamos BaseSettings para validar tipos de datos. Si accidentalmente pones un número donde va una cadena, el sistema te avisará al arrancar.

Seguridad por Capas: El uso de os.getenv permite que, cuando lleves esto a producción (AWS/Heroku), no tengas que tocar el código. Solo cambias las variables de entorno del servidor.

Mantenibilidad: Si mañana decides cambiar el tiempo de rotación de los logs, solo vienes a este archivo. El resto del sistema no se entera de cómo se gestiona el cambio.

Lo que hemos implementado:
Inyección de Dependencia: Al usar dependencies=[Depends(validate_api_key)], hemos creado un punto de control obligatorio. Si la llave no viene en la petición, FastAPI responde automáticamente con un 403 Forbidden sin siquiera ejecutar tu lógica.

Seguridad Auditada: Si alguien intenta hackearte, el logger.warning registrará la IP y la llave falsa que intentaron usar.

Flexibilidad: El endpoint /status sigue siendo público para que el Dashboard pueda refrescarse cada 5 segundos sin complicaciones, pero nadie puede alterar nada sin la llave maestra.

Siguiente paso crítico:
Para que esto funcione, debemos actualizar el Dashboard (HTML/JS) para que "aprenda" a usar esa llave. Si intentas usar el botón "Terminate" ahora mismo, fallará porque el Dashboard todavía no envía la X-Sentinel-Key.
