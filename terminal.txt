## 2. Manual de Operaciones: El Orden de Comando

Guarda esta tabla. Es tu "Cheat Sheet" para operar Sentinel-Q desde tus dos terminales.

### 🐧 Terminal Debian 13 (Gestión de Infraestructura)

| Acción | Comando | Por qué usarlo |
| :--- | :--- | :--- |
| **Limpieza Total** | `docker compose down --volumes` | Borra contenedores, redes y datos temporales. Úsalo para "resetear" todo. |
| **Construcción** | `docker compose up -d --build` | Lee cambios en el código y el `.env`, y levanta el sistema en segundo plano. |
| **Auditoría** | `docker logs -f sentinel_app_container` | Ver en tiempo real qué está haciendo el sistema y si hay errores. |
| **Reinicio Rápido** | `docker compose restart app` | Reinicia solo el código Python (limpia la RAM/Scheduler). |

### 🪟 Windows PowerShell (Gestión de Objetivos)

| Acción | Comando (Resumido) | Por qué usarlo |
| :--- | :--- | :--- |
| **Comprobar Salud** | `Invoke-RestMethod http://192.168.1.216:8000/status` | Verifica si la iMac está respondiendo antes de enviar órdenes. |
| **Iniciar Vigilancia**| `Invoke-RestMethod -Method Post ... -Body $body` | Envía un nuevo target al sistema para que empiece a monitorear. |
| **Detener Alerta** | `Invoke-RestMethod -Method Delete .../terminate/ID` | Detiene el bombardeo de Telegram para un ID específico. |
