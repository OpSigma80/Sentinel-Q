SENTINEL-Q: PERSISTENCE LAYER EXPLANATION

Architecture flow:
- Pydantic validates inbound data
- SQLAlchemy ORM maps Python objects to database rows
- the Repository layer isolates persistence from business logic

Key implementation detail:
- `self.db.merge(...)` helps avoid duplicate-ID conflicts when the same target is submitted again

Security note:
- ORM-based queries reduce SQL injection risk by avoiding manual string concatenation
