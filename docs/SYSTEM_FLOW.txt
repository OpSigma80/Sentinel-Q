==========================================================
SENTINEL-Q: SYSTEM FLOW
==========================================================

1. STARTUP
- the system reads persisted targets from the database
- if no records exist, the scheduler stays idle

2. WATCH CREATION
- an API request stores a target and schedules monitoring

3. CHECK LOOP
- the Checker probes the target at the configured interval

4. ALERTING
- on failure, the Notifier sends the Telegram request asynchronously
==========================================================
