Configuration:
- `config.py` uses typed settings loaded from `.env`
- the settings object is shared as a singleton-style instance

Domain model:
- `ServiceTarget` is the core monitored entity
- `HttpUrl` validates monitored service URLs

Networking:
- `http_client.py` performs async outbound checks
- exceptions return a controlled fallback status instead of crashing the app

Checker flow:
- updates target state after each check
- logs healthy and failing outcomes

API entrypoint:
- `main.py` initializes FastAPI
- startup hooks prepare the runtime environment before serving traffic
