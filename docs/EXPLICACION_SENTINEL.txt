==========================================================
SENTINEL-Q: TECHNICAL PROJECT EXPLANATION
==========================================================

Key files:
- `__init__.py`: marks directories as Python packages
- `pyproject.toml`: declares packaging metadata and dependencies
- `.env`: stores secrets and environment configuration
- `config.py`: Pydantic Settings singleton for typed configuration
- `main.py`: FastAPI application entrypoint and startup lifecycle

Development command:
- `uvicorn sentinel.main:app --reload`

Command breakdown:
- `sentinel.main` points to the package and module
- `:app` points to the FastAPI application object
- `--reload` is intended for development only
