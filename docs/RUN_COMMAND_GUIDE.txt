
==========================================================
        GUÍA DE EJECUCIÓN: SENTINEL-Q
==========================================================

COMANDO: uvicorn sentinel.main:app --reload

SIGNIFICADO:
- uvicorn: El motor de ejecución (Servidor).
- sentinel.main: La ruta al archivo de entrada.
- app: La variable FastAPI dentro de ese archivo.
- --reload: Modo desarrollo (Auto-reinicio).

RECOMENDACIÓN: 
No uses --reload en un servidor de producción real, ya que 
consume más recursos. Es solo para nuestra fase de construcción.
==========================================================
