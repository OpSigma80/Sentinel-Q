==========================================================
SENTINEL-Q: RUN COMMAND GUIDE
==========================================================

Primary development command:
- `uvicorn sentinel.main:app --reload`

Meaning:
- `uvicorn` starts the ASGI server
- `sentinel.main` points to the package and module
- `:app` selects the FastAPI instance
- `--reload` is for development only and should not be used in production
