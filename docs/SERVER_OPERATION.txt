
==========================================================
        NOTAS DE OPERACIÓN DEL SERVIDOR (DEV MODE)
==========================================================

1. RECARGA AUTOMÁTICA (RELOAD):
   Uvicorn vigila toda la carpeta Sentinel-Q. Si generas 
   un archivo .txt en la carpeta docs/, el servidor se 
   reiniciará. Esto es normal.

2. ERRORES DE SPAWN/TRACEBACK:
   Si ves un error largo de 'multiprocessing' al guardar, 
   no te alarmes. Es una colisión temporal de procesos. 
   El servidor siempre intentará levantarse de nuevo.

3. ESTADO DE SALUD:
   Mientras veas el mensaje "Sistema Operativo", el 
   Scheduler está corriendo en segundo plano y la base 
   de datos está conectada.
