----------------------------------------------------------
DOCUMENTACIÓN DEL CÓDIGO (Línea por Línea)
----------------------------------------------------------

[MAIN.PY]
- app = FastAPI(): Crea la instancia del servidor web.
- @app.on_event("startup"): Ejecuta procesos antes de aceptar tráfico.
- @app.post("/check-once"): Endpoint de prueba para validar la conexión.

[CONFIG.PY]
- BaseSettings: Clase que mapea el archivo .env a variables de Python.
- env_file = ".env": Indica dónde buscar los secretos.

[LOGS Y COMANDOS]
- uvicorn sentinel.main:app: 
    * 'sentinel.main' -> busca la carpeta src/sentinel y el archivo main.
    * 'app' -> es la variable que creamos en main.py.
- --reload: Reinicia el sistema automáticamente al detectar cambios.
